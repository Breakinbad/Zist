# ZIST landing page — polished prototype

Open `index.html` directly in a modern browser. The two large lifestyle images are embedded inside the HTML, so the page works as a single file and does not need an internet connection.

The `assets/` folder also contains standalone high-quality versions of the hero and closing images for future deployment or editing.

The email form is still an MVP demo: submitted addresses are stored only in the visitor's browser (`localStorage`). Connect this form to Supabase/Resend before collecting real signups.
